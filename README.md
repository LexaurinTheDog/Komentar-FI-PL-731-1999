# Suomen perustuslain (731/1999) kommentaari

Kommentaari suomalaiseen säädökseen: **Suomen perustuslaki 11.6.1999/731**. Kommentaari kattaa **132 kommentoitavaa yksikköä** — perustuslain johtolauseen sekä 1–13 luvun kaikki 131 pykälää — **5 kommentaarin luvussa**; kunkin yksikön kohdalla esitetään säännöksen sanamuoto sellaisenaan ja sen jälkeen kommentaari.

Tekstin tila: Finlexin ajantasainen lainsäädäntö, versio **20180817** (ajantasaistettu **5.10.2018**, viimeisin lähteessä mainittu muutos L 5.10.2018/817, voimaan 15.10.2018).

## Sisällysluettelo

Ks. [INDEX.md](INDEX.md). Menetelmän kuvaus on tiedostossa [00-johdanto.md](00-johdanto.md).

## Menetelmä

Kommentaari on laadittu **yksinomaan paikallisten aineistojen perusteella** (Finlexin avoimen datan ajantasainen säädösteksti), ilman kaupallisia oikeudellisia tietokantoja. Säännösten sanamuoto on siirretty lähteestä koneellisesti ja sanatarkasti. **Oikeuskäytäntö ei sisälly tähän versioon** — se lisätään erillisessä vaiheessa.
